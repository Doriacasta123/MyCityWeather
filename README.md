# ☀️ MyCityWeather 🌧️

## ✨ What's This All About?

Hey there, weather watcher! Welcome to **MyCityWeather** — a simple and elegant web app that lets you check the current **weather conditions** of any city in just one click. Enter a city name and instantly get the **temperature**, **weather description**, and the city name in a clean, responsive display.

---

## 🔎 Features

- 🌍 **Search for any city** and get live weather information  
- 🌡️ **Temperature in Celsius** and condition description in Spanish  
- ⚡ Instant results with clear layout  
- 🧼 Clean, centered interface for all screen sizes  

---

## 🛠️ Tech Stack

- **HTML** – Structure of the app  
- **CSS** – Styling and layout  
- **JavaScript** – Functionality and API integration  
- **OpenWeatherMap API** – Real-time weather data
